# oMLX pre-v0.5.4 results archive

Files here predate the oMLX revival (re-evaluated and promoted to `auto-coding`
shadow-shift on v0.5.4, since upgraded to v0.5.7 — see `docs/reports/OMLX_DECISION.md`
§Re-evaluation v3 2026-08-02). They were run against v0.3.8.dev2, the version
that got the original **RETIRE** verdict (KV cache not functioning, 4-5% slower

currently-deployed engine and **must not be used to judge current oMLX
behavior** — use the `omlx_v3_*` and `daily_soak_direct_omlx_*` files in the
parent directory (2026-08-02 onward) instead.
