# OT-PROC-007 Patch Evaluation Procedure

## 2.1
Every 35 calendar days the Systems Security engineer pulls the list of security
patches released since the last evaluation from the documented patch sources,
evaluates each for applicability to in-scope Cyber Assets, and files the
evaluation record. Evidence: the dated patch evaluation worksheet.
