# Bully SA7 — Live Data-Plane Census V1

This document indexes the generated Phase 0 census required by
`TASK BULLY SA7 DATA PLANE AND INVESTIGATION V1.md`. The source of truth is
[BULLY_DATA_PLANE_CENSUS_LIVE_V1.json](BULLY_DATA_PLANE_CENSUS_LIVE_V1.json),
generated by `scripts/sa7_live_census.py` from the registered source
connectors.

The JSON artifact contains per-source mode, verified capabilities, schema
confidence and bindings, time comparability, entity links, tier, quality,
access cost, sensitivity, record count, freshness, audit entries, and blind
spots. It is generated from live profiles rather than maintained as a status
table.

The generated run registered eight sources: live Splunk and the
case-history, asset-context, and advisory query-in-place sources; plus attack
data, flaws.cloud CloudTrail, invictus CloudTrail, and detection coverage
through ingest. The live catalog proof selected different source sets for
telemetry and response coverage, with exclusions retaining their
missing-capability reasons.

## Generated blind spots and findings

The current named remainder is the unavailable lab AD/Proxmox inventory
endpoint. Asset context is still derived from indexed entities, and the
finding is retained in the artifact rather than silently treating inventory
as present. Capability-level blind spots are enumerated in
`census.blind_spots`.

No investigation-base or later-phase work is claimed by this record. Phase A
remains governed by the separate L.10 gate evaluation.
