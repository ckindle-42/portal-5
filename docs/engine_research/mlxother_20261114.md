## 1) oMLX (incumbent baseline)

**Canonical:** https://github.com/jundot/omlx (accessed 2026-11-14). README states: "LLM inference server with continuous batching & SSD caching for Apple Silicon — managed from the macOS menu bar" (jundot/omlx README, accessed 2026-11-14). Project page reports 23.6k stars, topics apple-silicon/mlx/openai-api/inference-server, Apache-2.0, latest activity recent (accessed 2026-11-14). README highlights: continuous batching via mlx-lm BatchGenerator, tiered hot RAM + cold SSD KV cache (paged, safetensors, prefix sharing/CoW, survives restart), LRU eviction/pinning/TTL/process memory enforcement, OpenAI/Anthropic compatible APIs, tool calling/structured output, per-model settings (alias, type override, profiles), GGUF/external engine options, Claude Code optimizations (SSE keep-alive, context handling), configurable concurrency (default 8), SSD cache sizing (`--paged-ssd-cache-dir`, `--hot-cache-max-size`, `--paged-ssd-cache-max-size` auto default noted), API key auth, admin UI, model downloader, optional MCP tools, `omlx serve --model-dir ...` (jundot/omlx README, accessed 2026-11-14). README also documents MTP-related behavior indirectly via model support/perf notes in ecosystem and repo evolution; experimental multi-mac/distributed and prefill accelerator are separate features (README, accessed 2026-11-14). **Version in this repo context:** "oMLX current version" not pinned as a literal string in `engine_h2h.yaml` (incumbent is `kind: external`, service-managed via launchctl on this host per config comments); current production endpoint in bench config is `:8085` (`config/bench_engines.yaml`, accessed 2026-11-14).
