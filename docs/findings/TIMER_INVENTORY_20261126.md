## Rule used

`KILL-ON-STALL` ends the observed operation only after its observable progress has been idle for the stated window. `KILL-ON-CLOCK` ends an operation at a fixed duration regardless of progress. `REPORT-ONLY` records elapsed time, schedules a poll, or releases a coordination/idle guard without cancelling active model work.

The media UAT poller previously treated an unchanged coarse `running` stage as stalled after 300s. It now continues polling known-active jobs because the job API does not expose renderer-internal work. A status/API surface that is unavailable still uses the 300s no-observation idle failure.
